## Featured Projects

### Cross-Lingual News Classification using Transformer Models
**Technologies:** Python, PyTorch, BERT, Hugging Face Transformers, NLP
- Implemented multilingual NLP system using transformer architectures (mBERT, XLM-R) for cross-lingual news categorization across 4+ languages.
- Built complete ML pipeline: data collection, text preprocessing with Hugging Face tokenizers, model fine-tuning, and evaluation.
- Implemented domain adaptation techniques and data visualization for model performance analysis.

### [PES-IEEE-ETCC Conference Website](https://github.com/Vaarun-Kamath/PES-IEEE-Conference-Site)
**Technologies:** Next.js, React, TypeScript, Tailwind CSS
- Developed full-stack conference website with dynamic navigation, mobile-responsive design, and server-side rendering.
- Built RESTful APIs for data management and integrated frontend with backend services.
- Deployed application for production use handling 500+ conference attendees.

### RISC-V Performance Profiler
**Technologies:** Python, C++, Spike, Verilator, Git
- Developing profiling application for RISC-V instruction analysis and performance monitoring.
- Created Python scripts for data conversion, parsing, and automated report generation with visualization.
- Built command-line interface and implemented efficient file parsing logic using C++ data structures.

### Vedic Arithmetic Unit on FPGA
**Technologies:** SystemVerilog, Python, PYNQ-Z2, Vivado, C
- Designing embedded arithmetic processing unit on Zynq FPGA platform with hardware-software co-design approach.
- Implemented C-based control software for hardware communication over AXI interface.
- Developed Python testing framework for performance benchmarking and validation.

### Single Cycle RISC-V Processor
**Technologies:** SystemVerilog, Vivado, C++, Assembly
- Implemented complete single-cycle RISC-V processor from scratch supporting RV32I instruction set.
- Designed processor datapath and control logic at circuit level, including memory interface and register file.
- Developed firmware-level test programs in C and assembly language to verify instruction execution.

### Layered Testbench for Shift Register
**Technologies:** SystemVerilog, Python, EDA Playground
- Built comprehensive automated testing framework with transaction-based methodology.
- Implemented automated test script generation with constrained-random stimulus.
- Developed validation checks and coverage collection mechanisms.

### ML Classification Systems
**Technologies:** Python, scikit-learn, Pandas, NumPy, Kaggle
- Developed decision tree and ensemble learning models for classification tasks.
- Applied machine learning to structured data problems including logic gate classifier.
- Completed Kaggle competitions including Titanic survival prediction.

### Admissions CRM Core
**Technologies:** Next.js 14, TypeScript, Supabase, PostgreSQL, Edge Functions, Tailwind CSS
- Developed comprehensive MVP for admissions CRM system with lead management and task workflows.
- Designed normalized SQL schema for leads, applications, and tasks with complex foreign key relationships.
- Implemented Row Level Security policies and TypeScript-based Edge Functions.

### PD-YOLOv7: Edge-Optimized Object Detection
**Technologies:** Python, PyTorch, OpenCV, ONNX, YOLOv7, Knowledge Distillation
- Optimized YOLOv7 object detection architecture for deployment on resource-constrained edge devices.
- Implemented teacher-student knowledge distillation framework and channel pruning algorithm.
- Applied INT8 quantization-aware training to minimize model footprint.

### Real-Time Hand Tracking System
**Technologies:** Python, OpenCV, NumPy, Computer Vision
- Built real-time hand tracking and gesture interaction system using classical computer vision techniques.
- Engineered custom CV pipeline using HSV color space thresholding and morphological operations.
- Designed distance-based state machine for gesture-based interaction.

### Binance Futures Trading Bot
**Technologies:** Python, python-binance API, AsyncIO, REST APIs
- Developed algorithmic trading bot for Binance Futures Testnet capable of executing complex order types.
- Implemented order management system supporting Market, Limit, and Stop-Limit orders.
- Built secure architecture using environment variable management and comprehensive logging.
